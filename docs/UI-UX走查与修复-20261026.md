# 拾光小相 UI / UX 走查与修复

日期：2026-10-26。范围为现有 Skyline / glass-easel 小程序；沿用浅色亮蓝与现有深色主题，复用既有 TDesign 图标、滑块和原生动效，不引入 WebView。本轮在现有设计系统内修正布局、导航和状态反馈。

## 已修正的问题

| 问题 | 用户影响 | 修正 |
| --- | --- | --- |
| 规格详情先展示长说明，制作方式靠后 | 不容易发现核心换底色功能 | 将两种制作方式移至标题后，提供选中标识；主要按钮明确显示智能换底色或原图适配 |
| 详情信息密度高 | 必须滚动才能理解下一步 | 首屏保留尺寸、底色、格式、文件大小；详细要求与官方来源按需展开，底部动作固定 |
| 编辑中选择考试规格重新要求选图 | 当前照片与编辑上下文被打断 | 所有规格从事件通道返回原编辑页，沿用当前照片和底色；相同像素但不同考试也会重新应用文件规则 |
| 原图适配发现底色不符合要求时需回退重选 | 核心功能切换成本高 | 提供“智能换底色”，直接沿用当前照片与考试规格进入智能制作 |
| 已匹配比例仍显示两个不可用滑块 | 用户不知道为何拖不动 | 只展示实际可移动的轴；无需裁剪时说明比例已匹配 |
| 修改裁剪或重新适配失败仍有旧预览 | 旧结果可能被误认为新结果 | 参数变更与处理开始时同步清除旧结果、旧品牌预览；失败时无法导出，保留原照供重试 |
| 分类内搜索无结果只有清空关键词 | 可能误以为没有该考试规格 | 增加“在全部分类搜索”，保留关键词并扩大搜索范围；切换分类及打开详情时收起键盘 |
| 独立自定义水印后端尚未部署 | 用户设置完才遇到接口失败 | 用运行配置明确声明服务能力，旧服务默认关闭生成；页面提前说明可本地预览，提供重新检查，已完成的历史结果仍可导出 |
| 水印间距滑块只改变数值 | 操作没有可见反馈 | 水平与垂直排布间距随滑块变化，处理期间锁定参数 |
| 裁剪格式说明与实际输出不一致 | 无法判断输出质量和体积 | 更正为 PNG、最长边4096px；保存页对考试文件要求补充提示 |
| 草稿缩略图失效后留空 | 用户无法判断是否还能打开 | 首页、作品页提供图片占位与作品页提示，保留继续编辑入口，不删除草稿 |

## 验证

- `node --test tests/*.test.cjs`：113 项全部通过。新增12项回归，覆盖复用照片改规格、同尺寸考试规则变化、分类搜索恢复、水印能力检查及迟到响应、间距反馈、原图直接转换底色与导航失败重试；旧考试失败用例增加旧预览清空断言。
- Java 17 执行后端测试：5 项全部通过。Java 8 `mvn -DskipTests package` 成功。
- 微信官方开发者工具实际显示 Skyline；复核首页、规格目录、详情、考试原图适配、水印页、我的、作品。通过原生底栏实点“我的 → 作品”，页面与选中态正确切换。
- 国家公务员考试详情在现有 iPhone 12/13 mini 模拟器首屏显示两种方式、关键要求和固定操作按钮；切换智能模式后按钮为“选照片，智能换底色”。
- 搜索“国考”并选择教育分类得0项，扩大至全部分类后恢复1项，关键词保留。
- 实际原生事件通道验证：编辑 → 目录 → 注册会计师详情 → 使用此规格，返回原编辑页，保留演示图片并收到178×220及CPA规则。此项将图片处理方法替换为页面实例记录桩，未发起云端抠图。
- 演示图本机适配CPA实际输出178×220 JPEG，约17KB，品牌水印预览单独生成；页面仅显示可移动的上下滑块。原图为蓝底，界面仍明确提示该规格要求白底，并提供智能换底色入口。
- 当前线上配置没有水印能力声明，页面实际显示“水印生成暂未开放”，生成按钮禁用，可本机预览样式。
- 截图与数据见 `docs/design/exams-watermark-20261026/ux-*.png` 及 `ux-*-evidence.json`。截图经过视觉检查；原生自动化跨页过快曾超时，等待页面稳定后分别验证了事件通道和页面结果。

## 当前边界

- 本轮未部署 Java 或 Python，未启动本地后端，API仍指向现有HTTPS地址。新Java配置接口在部署后才返回 `watermarkEnabled: true`，届时独立自定义水印工具自动开放生成。
- 核心智能抠图、换底色请求参数不变；品牌水印预览与5次免费保存、激励视频增加次数的既有规则不变。
- 未操作真实相册、真实广告、真实登录或新增真实云端作品。真机相册权限、真实广告库存、独立水印服务端字体与生成效果仍需对应环境联调。
- 本轮原生视觉验证为开发者工具浅色模式，未声称完成深色真机、所有屏幕尺寸或帧率测试。
- 本次交付包含 Git 提交与推送，不部署后端、不提交微信审核。

## 提交前复查补充

- 保存会话或原图失效时，显示明确恢复说明，主按钮切换为“返回编辑”；没有上一页时回到首页。
- 预览读取失败时，可在当前页“重新加载预览”，仍通过本机位图生成品牌水印，重试不触发云端保存、不消耗次数。
- 本地草稿删除、云端记录删除从确认阶段开始防重复；确认框失败、删除失败均恢复可重试状态，退出页面或切换账号后不继续删除。
- 云端页明确说明这里是已经通过保存次数校验的无水印成品，可以直接查看下载，避免与未解锁的品牌水印预览混淆。
- 水印文字采用直接控制字符检查，接受正常中英文与数字，拒绝换行、制表及不可显示的控制字符。此处是水印格式校验，没有恢复个人昵称的文字内容审核。
- 最终新增5项前端回归与1项Java回归；前端合计113项、后端合计5项全部通过。Java8再次打包成功。
- 原生验证失效保存页恢复首页、品牌预览失败后重新生成成功；云端说明通过真实底栏进入作品页后复核。截图为 ux-export-unavailable.png、ux-export-recovered.png、ux-cloud-explanation.png，已逐张查看。自动化偶尔返回旧画面，已排除后重新捕获，截图不包含真实用户的照片。
