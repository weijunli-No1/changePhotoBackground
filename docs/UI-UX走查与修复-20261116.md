# UI / 交互走查与修复（2026-11-16）

范围：首页与工具目录、公共规格弹层、规格详情、证件照编辑、考试原图适配、压缩裁剪、水印、导出、作品、会员、我的、资料与帮助页面。沿用现有 Skyline / glass-easel 界面与视觉风格。

## 本轮修复

| 页面 | 问题与触发条件 | 修复后的行为 |
| --- | --- | --- |
| 公共规格弹层 | 可用高度较低时所有内容都不可收缩，确认栏被裁到屏幕外 | 内容区独立滚动，标题与确认栏保持可达；按原生测量收高，随键盘与错误提示重算；聚焦输入及校验失败时自动定位 |
| 我的 | 会员说明的 WXML 字符串字面量包含换行，完整模板编译失败 | 修正为合法单行字面量，全部模板编译通过 |
| 证件照编辑 | 空页面或抠图失败后点击预设底色，会进入无法结束的处理中状态 | 没有有效抠图时禁用并弱化底色控件，保持重新选图可用 |
| 证件照编辑 | 打开规格目录失败被当作照片处理失败，已有成品的保存操作消失 | 独立展示导航错误，保留成品与保存入口，重试时清除旧提示 |
| 水印 | 再次点击已选中的方向、颜色或模板会清除成品 | 同值操作保留结果，实际修改参数后才要求重新生成 |
| 考试适配 | 从分享进入时没有原图，出现空白预览和禁用的保存按钮 | 展示“选择原照”空态，选图后进入原有处理流程 |
| 考试适配 | 无效规格仍能选图，却无法处理 | 提供“重新选择规格”入口，阻止无效选图；导航失败可重试 |
| 规格详情 | 复制来源链接失败无反馈，连续点击会重复调用 | 展示复制中与失败提示，防止重复调用，退出后不弹迟到提示 |
| 个人资料 | 保存结束前切换账号，旧资料可能覆盖当前账号的全局展示信息 | 完成后再次核对账号，不覆盖新账号资料或错误返回 |
| 云端作品 | 删除与后台刷新并发，迟到的旧列表重新显示已删除作品 | 删除成功先移除本地项，再替换旧刷新；刷新失败也保留删除结果 |
| 导出 | 保存六寸排版后仍显示单张尺寸，切回单张或保存失败后尺寸残留 | 展示实际成品尺寸，单张与排版切换时恢复对应尺寸，忽略迟到信息 |
| 导出 | 已保存排版预览加载失败，重试却生成单张预览 | 使用已保存的实际成品恢复预览，避免图片与格式不一致 |
| 会员 | 页面退出后收到下单或支付取消回调，仍更新已卸载页面 | 保留订单恢复线索，停止对已卸载页面的更新 |
