# UI / UX 走查记录

日期：2026-10-22。范围：首页、规格弹层、证件照编辑、导出、本地工具、作品、我的及公共导航。代码尚未推送或发布。

## 修复

| 问题 | 处理 |
| --- | --- |
| 用户真机反馈自定义 TabBar 能看到但无法切换 | 替换为微信原生 TabBar，使用深浅主题独立图标。开发者工具通过可访问性界面实际点击“工具→作品→我的→工具”，路径和选中图标均更新。原自定义层的具体真机命中原因尚未通过设备日志确认，不将推测写成结论。 |
| 深色页面大面积偏绿 | 页面 #121212、表面 #1c1c1e、软底 #29292c、画布 #202022；品牌绿只保留在强调色。导航、底栏、规格选择器一起统一。 |
| 辅助文字偏浅、深色错误字难读 | 加深浅色说明文字，新增深浅色错误语义颜色。 |
| 规格弹层小屏／键盘下可能超出屏幕 | 标题固定，内容滚动，按窗口和键盘高度调整弹层；聚焦自定义宽高时滚动到输入区；输入宽度可收缩。 |
| 隐藏原生 TabBar 后模拟器底部黑边 | 不隐藏原生导航，弹层位于导航上方，切换导航自动关闭弹层；最新小屏截图已无该黑边。 |
| 本地处理失败仍可保存旧结果 | 参数变化后立即清空旧输出，处理失败时不能导出旧图；重试成功恢复。 |
| 恢复草稿后换色失败，图片与底色记录不一致 | 初始化已应用底色，失败回退到真实的原底色。 |
| 同一结果再次保存会重复消耗云端次数 | 当前导出页按账号、输出类型缓存服务端成功结果，重复下载直接保存；电子照片和排版分别计首次生成。 |
| 云端请求失败和“没有作品”同时出现 | 首次失败显示独立错误态和重试按钮；刷新失败保留旧列表。 |
| 配额查询失败仍展示通用免费次数 | 登录用户显示查询中／暂未获取／失败重试，成功后展示实际配额。 |
| 处理中滑块仍可拖动但值被忽略 | 处理中禁用滑块；只在对应方向确有可裁剪余量时显示构图滑块。 |
| 原生导航下导出截图出现按钮裁切 | 页面改为按父容器百分比高度布局，检查顶部页面与保存按钮真实边界，并在编译稳定后复查完整按钮。 |
| 本地导出尺寸重复出现 | 保留一处尺寸信息。客服按钮文字粗细与列表统一。 |

## 验证证据

- 一方源码 JS / JSON 检查、WXML 编译、39项回归测试。
- 原生运行：基础库3.17.5，Skyline。初版430×932，本轮375×812设备，原生底栏下页面可用375×730。
- 实际界面点击三项 TabBar 成功；另用官方 miniprogram-automator 逐页检查规格弹层、错误态、本地裁剪、导出和个人页。后端保存及真实广告未被测试调用。
- 键盘布局通过传入300px高度事件验证收缩与滚动，属于键盘事件模拟；实际手机键盘仍需验收。
- 系统窗口后续再次提示锁屏，未能用界面切换模拟器系统深色。已更新中性主题代码；自动化强制深色截图尝试遇到开发者工具页面元数据错误，临时样式均已恢复，不把该项记作真实系统主题切换通过。
- 演示裁剪草稿使用项目生成素材，结束后只移除本轮新建的对应测试草稿，保留此前已有草稿。

## 设计对照

参考 `design/skyline-redesign-concept-v1.png`，本轮用图片查看工具重新查看参考及实际 Skyline 截图。目标为原生小程序，因此以微信开发者工具截图验收，不以浏览器替代。

| 对照点 | 结果 |
| --- | --- |
| 首页文案与层级 | 主要标题、证件照入口、三项工具、继续编辑顺序一致，首屏没有新增宣传文案。 |
| 排版与字号 | 保留较大的标题、清晰的主操作和安静的辅助文字，小屏主按钮及工具列表无横向溢出。 |
| 配色 | 浅色仍为白底墨绿；按用户最新反馈将深色背景明确改为中性灰。 |
| 人像素材 | 保留同一生成式演示人像和蓝底处理，页面不预置虚构作品记录。 |
| 控件与容器 | 首页仍为开放工具列表；规格弹层增加滚动；底栏有意替换为系统原生以修复真机点击。 |
| 底部操作与安全区 | 裁剪和导出主按钮在底部安全区上方；TabBar 的安全区由微信原生处理。 |

已按原概念及本轮明确变更核对主要版式、文案、照片、文字层级和底部操作。保留的设计差异：原概念顶部重复“下一步”已移除；无草稿时显示真实空态；自定义色使用调色盘；增加实际像素信息；原生底栏尺寸遵循微信系统。深色系统切换、真实广告和相册授权仍需手机复核。
