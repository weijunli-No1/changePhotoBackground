# UI 与交互走查 · 2026-11-04

沿用校园 V3 设计，对首页、工具、规格、编辑、保存、作品、个人中心检查可见布局与状态反馈，修复搜索位置、重复操作、异常恢复和错误文案。保留工作区既有业务改动；未部署后端或发布小程序。

## 本轮修复

| 问题 | 修复 |
| --- | --- |
| 工具筛选后保留旧滚动位置，可能看不到结果 | 搜索、清空和切换分类时回到结果顶部 |
| 编辑页重新选图、裁剪与顶部返回缺少连点保护 | 增加操作互斥；失败后释放锁；离开页面后的选图失败不弹提示 |
| 顶部“调整照片”没有操作响应 | 接入裁剪入口，提供至少 44px 点击高度；导航失败显示错误，重试清除旧错误 |
| 无照片时显示“照片处理失败”“已保留当前照片” | 改为选择照片提示，只有实际存在照片时才说明已保留 |
| 保存失败信息在滚动内容中，可能不在视口 | 错误固定在底部主按钮上方，当前失效文件截图已复核 |
| 预览准备中仍可能通过入口调用保存 | 主操作与保存函数同时阻止，避免提交旧预览对应的状态 |
| 六寸排版保存后仍使用窄人像宽度 | 成功排版预览恢复可用宽度并保留 aspectFit；本轮没有执行真实保存验证 |
| 保存页、个人中心查询权益失败后一直显示“正在同步” | 区分加载与未知状态，失败退出加载；保存页可点提示重试；并发查询合并 |
