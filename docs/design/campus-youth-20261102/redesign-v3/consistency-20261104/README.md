# 全页面 UI 一致性修正与原生走查

完成日期：2026-11-05。沿用已确认的校园 V3 设计，覆盖全部 15 个页面及公共组件。此次修改在本地工作区完成，未发布小程序或部署 Java 服务。

## 已落实的修正

- 提取共享颜色、字体、字号、圆角、边距变量。正文、行标题、分组标题和说明文字按角色收拢，保留校园蓝、黄色主视觉按钮与绿色横幅。
- 主按钮统一 96rpx、30rpx/600、28rpx 圆角；窄屏保证至少 48px。次操作至少 44px，统一按下与禁用态；降低退出登录的强调程度。
- 原生截图发现 Skyline 未正确应用 `max()` 最小高度，改为 rpx 与窄屏媒体规则；首页主按钮高度恢复正常。
- 深色选中态、滑块、导航和底栏图标统一浅蓝。补齐组件内主题变量，修正规格弹层禁用文字被深色普通文字覆盖的问题。
- 搜索框、卡片、选项、输入框和弹层使用相应的统一圆角；裁剪、压缩、水印的选图区域、用途说明保持一致。
- 移除编辑与保存预览中围住整个 `aspectFit` 容器的白框，避免留白区域被误画成照片边框。
- 会员能力与权益查询分开：旧配置缺少能力标记时显示“暂未开放”，个人中心降为普通菜单项，不再反复请求未部署的会员接口；网络故障仍属于未知状态。有待确认订单时保留查单流程。
- 保存页优先显示实际额度。未部署会员时仍保留既有激励视频流程，必须完整观看并由服务端记录；不会授予会员或跳过保存限制。
- 修正会员已同步、额度查询失败时“重试”没有重新查询额度的问题。
