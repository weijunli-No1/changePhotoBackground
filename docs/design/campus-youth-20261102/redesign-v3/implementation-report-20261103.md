# 校园风 V3 · 原生实现与验收

日期：2026-11-03。

后续 UI/UX 走查与服务器地址修正见[走查记录](audit-20261103/README.md)，最新为140项测试通过。本文下方131项及原生流程为首次实现时的验证记录。

已按 V3 设计实现首页、全部工具、规格选择、制作证件照、预览保存、作品和我的，共7个核心页面，并实现处理、取消、失败恢复、保存成功的视觉状态。仍使用原生 Skyline / glass-easel、真实 WXML 控件与既有 TDesign 组件，没有以设计图或网页替代界面。

本轮未部署服务端、上传或发布小程序；原有后端、会员、认证等未提交改动均保留。

## 实现内容

- 统一白底、深蓝正文、校园蓝、草绿、柠檬黄与橙色点缀；增加共享跑道和星芒模板，装饰不接收点击。
- 首页加入校园标题、蓝色主卡、黄色制作按钮、相片白边与胶带、绿色考试入口；草稿继续使用真实数据和真实空状态。
- 工具目录采用彩色图标和分组列表；搜索和分类保留原逻辑。
- 规格页分为全部、常用证件、考试报名；常用规格先勾选，再经底部已选摘要与按钮继续。考试仍进入完整要求页，保留出处和原照适配规则；没有把概念图中的考试示例写死。
- 编辑页以大预览、蓝色规格条、黄色页签线和明确色块勾选组织操作；处理层保留取消入口，失败时突出重试和重新选图。
- 保存页保留实际尺寸、格式、水印和额度说明；成功回调后才展示成功状态与无水印结果。重复保存继续复用原缓存链路。
- 作品页增加独立继续编辑按钮并保留删除确认；个人中心使用绿色身份区、蓝色会员条、黄色查看权益、信息型额度提示和蓝色描边退出。
- 原生 TabBar 使用新的轮廓/填充图标；图标生成源位于 `scripts/generate-campus-icons.py`。

## 功能验证

`node --test tests/*.test.cjs`：131项通过、0失败。新增4项测试覆盖常用规格选中后确认、防重复选择、编辑页只回传尺寸、分类搜索及页面退出后的迟到结果。

37份前端 JS 语法检查通过，23份 WXML 结构检查通过，项目 JSON 可解析。微信开发者工具正常核心流程期间未采集到编译错误。

原生模拟流程实际走通：

1. 规格页点击二寸，已选摘要更新为413×579。
2. 使用项目既有的虚构成年样片进入编辑，模拟抠图与合成接口返回结果；切换到蓝底。
3. 检查处理中状态，点击取消后恢复可操作状态。
4. 展示网络失败，点击重试后恢复有效结果。
5. 进入保存页，切换六寸排版，再回到电子照片。
6. 点击保存，模拟相册写入回调后 `saved === true`，显示成功状态与无水印结果。
7. 工具目录输入“压缩”，只显示对应工具，可恢复全部。

上传、业务请求和相册写入均使用本地 mock，没有真实上传照片、扣除保存次数、播放广告、购买会员或写入相册。处理/失败状态还使用了临时页面数据进行展示检查，不能据此宣称真实网络故障链路已联调。

测试结束已撤销 mock，恢复原账号及导出会话，保留原有2份本地草稿，清理本轮生成的测试草稿和临时照片。截图中的昵称、次数、作品和照片均为演示状态，不作为产品默认数据。

## 与静态概念的有意差异和验证边界

- 沿用项目既有的独立成年男女样片，避免把概念图整张裁入 UI；人像身份与生成概念存在差异。
- 工具图标采用一致的 TDesign 图形；自定义裁剪图形、皇冠与导航图形有独立可维护源。没有复刻生成图中不一致的光泽效果。
- 考试目录展示真实项目数据与要求，完整条目可滚动；保留四种常用规格，不删减为概念中的两种。
- 保存页保留实际图片像素和水印说明，避免把所选规格等同于当前预览像素。本次 mock 返回的是400×560样片，不能用本次截图证明真实后端输出413×579正确。
- 首屏文案已按V3落地；工具说明、考试名称、会员未知状态及空状态沿用真实业务内容，不伪造概念中的示例值。
- 已完成浅色核心页面的概念与原生截图对照。补充深色/跨机型检查时，当前开发者工具出现图标字体未加载、渲染层空白及自动化响应超时；这些过渡截图已移除，深色动态切换不列为验收通过项，仍需真机复核。
- 已恢复原始浅色与 iPhone 12/13 mini 设置，重开本项目完整开发窗口后，375px首页正常渲染、图标正常、控制台错误过滤为空；最终截图为 `home-restored-375.png`。已停止挂起的本轮自动化CLI进程，没有关闭其他项目窗口。
- 未以本轮模拟验证代替真实人像服务、广告库存、支付、相册权限拒绝或真机动画手感验收。
