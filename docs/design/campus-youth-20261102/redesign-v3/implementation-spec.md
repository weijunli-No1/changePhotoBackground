# V3 实现约束

2026-11-03。用户已要求按 V3 设计编码。以本目录 01–05 图为视觉依据。

- 原生 Skyline / glass-easel，沿用 TDesign 图标与调色器，不以网页或整张设计图替代界面。
- 浅色：白底 #FFFFFF，正文 #142A43，蓝 #2358EE，绿 #16885D，黄 #FFE34C，橙 #FF7D43；辅助面 #EEF5FF / #EAF8F1 / #FFF1DE。保留深色支持，统一为同一校园品牌的深色可读变体。
- 左右留白 36rpx；标题 44–48rpx / 700，功能标题 32–36rpx / 600，正文 28rpx，说明 24rpx。按钮至少 44px，主操作约 96rpx，高对比度，圆角 28rpx。
- 组件：主按钮、描边次按钮、搜索栏、分组行、单选项、黄色标记线、跑道曲线、绿色提示条；装饰不响应点击并对读屏隐藏。
- 首页文案：青春，正好上镜 / 照片小事，轻松搞定 / 搜索工具，例如：压缩 / 证件照，轻松准备 / 考试报名·换底色·六寸排版 / 开始制作 / 常用工具 / 全部工具 / 考试报名照 / 四六级、考研等常用规格 / 继续编辑 / 查看作品。
- 工具页：照片小事，都在这里；原有六项工具、分类和搜索保留。规格页：为照片选个规格；常用预设可勾选并经底部按钮继续，考试保留完整详情、原照适配和审核说明，不伪造统一考试要求。
- 编辑：大预览、蓝色规格条、底色勾选、黄色页签标记；原图对比、取消处理、重试及保留草稿沿用真实状态。
- 保存：这一张，准备好啦；格式、尺寸、预览水印、真实额度；成功后显示相册保存结果，原保存计费/登录/广告/会员规则保留。
- 作品：我的作品 / 在这里，接着完成你的照片；横向草稿行、独立继续编辑和删除、草稿/云端下划线页签。
- 我的：绿色身份区、蓝色会员条与黄色查看权益、真实次数、信息型额度说明、设置分组、蓝色描边退出。
- 媒体：沿用项目已生成的独立成年男女样片（白衬衫、男杏色/女蓝色）；边框/角度/胶带/跑道均为真实节点，照片不叠加 UI 色罩。编辑与保存预览展示用户真实图片，不注入设计样片。无草稿/未登录时显示实际状态。
- 图稿中的演示作品、时间、昵称、次数不能写死进产品。会员价格由后端及原会员页面决定，个人页统一“查看权益”。
- 原生 TabBar 继续承担三个根页面导航，图形按设计换成蓝色填充选中/深灰轮廓，避免改变既有路由及安全区行为。

验收采用微信开发者工具原生截图与回归测试；实际后端、人像服务、广告、支付、真机相册另列验证边界。静态图的生成差异须在组件规范中统一，不据此新增业务。
