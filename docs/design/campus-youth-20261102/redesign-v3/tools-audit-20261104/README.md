# 工具页界面与交互走查 · 2026-11-04

延续校园 V3，检查裁剪、压缩和水印工具的空态、换图、失败恢复及导航。保留工作区既有改动，未发布小程序或部署后端。

## 本轮改动

- 裁剪、压缩、水印在无照片时，底部主按钮改为可点击的“选择照片”。压缩读取失败后同样可从主按钮恢复，避免重复出现两个选图操作。
- 裁剪/压缩换图先校验新照片，成功后才替换照片、重置裁剪和创建新草稿。读取失败或取消时保留原照片、生成结果、裁剪设置和草稿标识；读取期间禁止改参和导出。
- “用于制作证件照”与导出操作互斥；连点只导航一次，导航失败恢复按钮并显示重试提示，退出后不再导航。
- 两个工具页面的错误提示移到固定底部操作区，水印的取消处理入口也移到底部，避免必须滚动才能发现失败或取消操作。
- 水印草稿原图失效时清空不可用预览，引导重新选图；仅生成结果失效时保留原图和样式，引导重新生成，并刷新预览比例。选图期间不再生成或导出旧照片。
