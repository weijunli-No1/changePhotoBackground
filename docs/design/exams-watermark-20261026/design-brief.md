# 考试照片与水印设计说明

日期：2026-10-26。使用 frontend-app-builder 与 imagegen 技能，内置 ImageGen 生成三屏完整工作稿，图片为 concept.png。实际实现为原生 Skyline / glass-easel，不使用 WebView。

## 概念提示词与范围

生成三张并列完整390×844移动页面：规格目录、规格要求、水印编辑。沿用拾光小相纯白表面、亮蓝 #2563EB、深色文字和现有深色主题；搜索考试名/简称，分类横向切换，使用可扩展分组列表，底部固定自定义尺寸入口。详情同时展示输出像素、要求类型、格式、底色、体积、官方来源与下一步。水印页使用受限高度的原图预览、文字模板、透明度/字号滑块、方向选项、更多样式和固定生成按钮。无营销头图、无虚构数据、无审核通过保证；控件与文字全部由WXML/WXSS实现，不把概念截图当页面。

## 设计系统

- 背景与表面沿用 --sg-bg / --sg-surface；目录用 --sg-soft 分区。
- 主色 --sg-brand，浅色 #2563EB；深色继承项目既有变量。
- 左右间距36rpx；标题30–44rpx，正文26–28rpx，说明22–24rpx；系统中文字体。
- 单一列表容器内用分隔线，不为每个考试堆叠卡片；搜索与分类固定，内容滚动。
- 主要动作至少44px，安全区在footer-actions内处理；长规则可滚动，按钮始终独立可达。
- 考试适配只在本机修改尺寸、构图和JPEG体积；拖动构图时预览裁剪位置，松手才导出文件。
- 水印调参只更新预览，用户主动点击生成时上传；生成中参数锁定，可取消、失败重试。

## 根据官方资料修正的概念差异

- 国考采用已核对的2027年度指南，而非概念中的2026年度。
- 教资所列2026官方通知没有150×200固定像素，实际标注建议输出300×400，不能把概念中的150×200当作硬性标准。
- 考研600×800为3:4输出建议。原图较小时保留比例并输出实际像素，不放大制造清晰度。
- 四级和六级分别搜索与选择，并明确学校要求存在差异。
- 水印使用项目已有演示照片，预览缩在编辑区域内，避免挤出设置；最终效果以服务器生成图片为准。

## 原生视觉复核

使用微信官方miniprogram-automator截图，view_image对照concept.png与native-specs/detail/watermark等最终截图。检查列表层级、中文字体与单位、主题色、底部按钮、安全区、搜索无结果恢复、图片裁剪和水印设置。

浏览器无法运行原生WXML/Skyline，所以采用微信原生模拟器；没有使用浏览器网页替代渲染。375×812为模拟器视口，320×568是窄容器压力检查，不代表小屏真机或真实FPS。实机相册权限、键盘和线上Python字体/部署仍需后续联调。
