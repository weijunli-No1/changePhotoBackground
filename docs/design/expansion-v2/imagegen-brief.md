# 界面参考图生成简报

生成方式：内置 ImageGen；五张完整手机界面参考，不是上线图片或页面代码。先生成参考，再使用原生 WXML／WXSS／JS 实现。没有使用用户私人照片；实际界面沿用项目既有生成式演示人像。

共同提示要求：微信小程序“拾光小相”，375×812逻辑尺寸的完整竖屏，平面界面截图，无手机外壳；白色 #FFFFFF、墨绿 #174E45、正文 #17221F、次要文字 #626B66、照片画布 #EEF1F2。系统中文字体，标题约24px、区域18px、正文14px、说明12px；20px边距，44—48px可点击高度，控件圆角12px、主要照片区16px。留白清晰，无渐变、浮夸阴影、装饰徽章、虚构数据和未实现功能。线性图标匹配现有 TDesign；真实文字和交互由代码实现，图像只用于设计参照。

各屏内容要求：

1. `concept-home.png`：标题“今天想处理什么？”，搜索“搜索工具，例如：压缩”；横向证件照推荐“证件照，轻松准备／选规格、换底色、六寸排版／开始制作”及蓝底演示照片；常用工具更换底色、图片压缩、裁剪旋转；全部工具入口；继续编辑与查看作品；真实空草稿说明；底部首页、作品、我的。
2. `concept-library.png`：返回与全部工具标题；搜索工具名称或用途；全部、证件照、图片编辑分类；制作证件照、更换底色、图片压缩、裁剪旋转的开放式分组列表及用途说明，本地工具标本机处理；不放未来功能占位。
3. `concept-editor.png`：编辑证件照标题；顶部原图对比；大图预览；单个当前规格条；背景底色、裁剪构图两页签；白蓝红及自定义圆形底色控件；底部预览并保存。不得重复放规格页签，不增加第二个主要保存动作。
4. `concept-export.png`：预览与保存标题；灰色画布中的蓝底单张证件照；一寸与实际400×560像素说明；电子照片、六寸排版两行单选项及缩略图；实际保存机会说明；底部保存电子照片。照片占比清晰，格式说明与按钮可读。
5. `concept-profile.png`：我的标题；横向头像、微信用户、编辑头像昵称；中性保存机会区域；我的本地草稿、帮助与客服、隐私安全政策、用户须知；独立退出登录及保留草稿与资料说明；底部首页、作品、我的。头像、昵称和额度仅代表界面状态示意。

生成后有意调整：空状态用“作品”替代只指向照片的措辞；额度标题限定“证件照保存机会”。字体与系统胶囊遵循微信原生尺寸；实际内容、账号、配额和选中态由运行数据决定。详细对照与偏差处理见上级《界面升级与功能扩展方案》。
