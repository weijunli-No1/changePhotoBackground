# 晴空蓝与扇形人像 · 实施简报

用户要求：说明TDesign使用情况；浅色主题更明亮青春；首页展示一男一女，像手持扑克牌的扇形展开。

- 架构：原生Skyline／glass-easel + TDesign图标、调色器；保持现有信息架构、原接口与保存链路。
- 颜色：白色页面，主色#2563EB，文字#1E293B，辅助文字#5B6B82，浅面#F4F7FF／#EFF6FF，线条#E3EAF7；杏色仅来自男生样片。深色保持现有中性炭灰及原有品牌色。
- 首页：继续使用20px左右边距、现有字号系统；主卡约182px高，左侧两行标题、说明、至少44px按钮；右侧约148×150px照片扇面，两张照片各约82×122px，白边3px，底部锚点，男-12°、女+10°，两脸完整、互不遮挡。
- 保留文案：拾光小相／今天想处理什么？／搜索工具，例如：压缩／证件照，轻松准备／选规格、换底色、六寸排版／开始制作／常用工具／全部工具／更换底色／图片压缩／裁剪旋转／继续编辑／查看作品／还没有未完成的作品／开始处理后，会自动保留草稿／首页／作品／我的。
- 图形：保留现有代码原生工具图标及原生TabBar图形，仅换浅色选中颜色；不替换为概念图中自动改变的图标。
- 有意差异：概念图自动产生的按钮渐变、附加箭头和大块居中空状态不在设计要求内；实际沿用纯色按钮与紧凑草稿空状态，不增加这些元素。
- 新素材：虚构成年东亚男生、白衬衫、正面证件照、杏色底；女生沿用现有虚构样片；不使用用户照片。独立照片素材与照片边框／角度分开，扇形由WXML／WXSS实现。

生成方式：内置image_gen。概念图见concept-home.png。男生原提示词：单一虚构25岁左右东亚成年男性，短黑发无胡须、白衬衫、正面居中、平静自然表情、头顶留白、纯杏色#FFE0CC、均匀摄影棚光，无文字、边框、手或道具。发布素材只做尺寸与JPEG编码优化。

## 实施与检查

实际安装的TDesign版本为1.12.3（package.json声明^1.12.3）；使用t-icon、t-color-picker，首页、工作台和动效弹层为自定义原生组件。浅色主题同步覆盖全局sg／td变量、原生TabBar的文字与6张浅色图标、规格弹窗局部变量、白底选中勾和处理反馈。裁剪滑块读取实际主题，并通过wx.onThemeChange／offThemeChange同步颜色，不把浅色蓝色强加给深色滑块。深色页面背景及原有选中色保持原配置。
