# 拾光小相 · 开发验收说明

更新日期：2026-10-23。版本状态：上一轮代码已提交并推送，本轮昵称交互修改仍为本地开发版本，未部署、未提交微信审核。以下分节保留各轮验收范围，当前完整回归为91项。

## 已完成范围

- 首页、作品页、个人页、编辑工作台、独立保存页和协议页采用统一的白底墨绿界面。
- 所有页面保留 Skyline 渲染器和 glass-easel；原生 WXML / WXSS / JS 实现，没有引入网页或新前端框架。
- 规格先选后拍摄或选图，支持四种原有规格及100—3000像素自定义宽高。
- 编辑支持大图预览、原图对比切换、预设或自定义底色、规格切换、重新选图、先本地裁剪再制作证件照。
- 编辑与导出使用本地文件路径预览，中间 Base64 保存在处理逻辑中，避免把大图片反复传入 `setData`。
- 保存页统一选择电子照片或六寸排版。排版示意不调用生成接口、不扣额度；点击保存后才进入原处理链路。电子照片维持原有高清图优先规则，并显示实际输出像素。
- 保存时在当前流程完成微信登录；登录取消、失败、广告取消和网络错误均保留当前作品。
- 激励视频使用用户提供的广告位，完整观看并记录奖励后继续原单图或排版操作。增加重复点击保护、失败提示、加载重试和卸载清理。
- 同一导出页按账号和电子照片／排版缓存已经成功的云端结果，重试相册写入或再次下载不重复消耗云端保存次数。
- 本地压缩支持三档质量和三档最长边；采用原生 `compressImage`，显示实际结果体积。
- 裁剪支持原比例、1:1、3:4、4:3、9:16，支持90度旋转及构图位置调整；支持离屏画布导出，不可用时使用真机2D Canvas。维持 Skyline。
- 最近8份草稿保存在持久目录，元数据不存大块 Base64；更新先写新文件，失败保留旧草稿；更新、删除和数量上限会清理对应草稿文件。
- 作品页区分本地草稿和云端证件照；云端查询、预览和删除仍调用原接口。
- 我的页面展示登录状态、服务端实际配额、草稿入口、客服和协议；草稿清理集中在作品的本地草稿页。隐私文案对应本地处理与云端处理的实际边界。
