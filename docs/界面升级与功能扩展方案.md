# 界面升级与功能扩展方案

2026-10-22。本轮目标：让用户更快找到合适工具、减少编辑和保存中的重复判断，并建立可增加功能的结构。继续使用 Skyline、glass-easel 和现有后端接口。

## 实施设计简报（概念图生成前）

- 底部固定三项：首页、作品、我的。首页负责发现与开始，作品负责继续与取回，我的负责账号、额度和帮助。新功能进入工具目录，不默认增加底部标签。
- 首页顺序：标题“今天想处理什么？”；搜索入口“搜索工具，例如：压缩”；证件照主入口“证件照，轻松准备”+“选规格、换底色、六寸排版”+“开始制作”；常用工具（更换底色、图片压缩、裁剪旋转）与“全部工具”；继续编辑与“查看作品”。无草稿时显示真实说明，不预置作品。
- 新增全部工具页：可输入名称／用途、清空、按真实类别筛选。当前类别为证件照、图片编辑；以配置注册功能，目录只展示已实现、可用的功能，不添加“敬请期待”入口。
- 证件照编辑：顶部轻量原图对比；中间照片；下方按“当前规格 → 背景底色／裁剪构图 → 控件”组织，去掉重复的规格页签。取消、失败恢复和草稿保留延续已修复行为。
- 保存页：照片预览、当前规格、两个紧凑格式选项、真实额度／失败提示；保存成功后的首要动作是完成，重复下载变为次要操作。沿用按账号与格式缓存的成功结果。
- 我的：横向紧凑身份区域、简洁额度区域；草稿清理、帮助、隐私与退出保持清楚，不把视频广告变成首页内容。
- 作品：继续沿用本地／云端区分，减少装饰性标题，草稿显示真实更新时间。资料、帮助、文档与本地工具继承同一组件尺度。

## 视觉系统

- 浅色背景纯白 #FFFFFF；照片区域 #EEF1F2；正文 #17221F；次要文字 #626B66；品牌色 #174E45。深色使用中性炭灰 #121212 / #1C1C1E，绿色仅用于操作和选中。
- 系统字体；页面标题24px左右、区域标题18px、正文14—15px、说明12—13px，核心触控区域至少44px；主要按钮48px左右。
- 20px页面边距，区域间距24—28px，行距与控件间距8—16px。大块照片区域圆角16px，操作和输入12px；不使用夸张阴影、渐变或装饰徽章。
- 图标使用现有 TDesign 线性图标；照片使用项目既有生成式演示素材，不重新生成真实用户或虚构作品记录。
- 概念图用于布局与视觉对照，所有文字、输入、按钮、目录均以原生代码实现。微信胶囊、状态栏和底部原生导航以平台实际尺寸为准。

## 扩展边界

工具名称、说明、类别、关键词、入口类型和显示顺序统一注册。首页常用入口、完整目录与搜索读取同一份配置。后续接入新类别或工具时增加条目和实际页面；不在展示层散落判断，也不在用户界面暴露实现配置。

新增功能仍应明确：输入是什么、在本机还是云端处理、输出是什么、是否登录／计次、失败后如何恢复。后台地址和图片处理协议本轮不调整。

## 已落地结构（2026-10-23）

1. 首页不再承担完整工具列表，保留一个主推荐、最多三个常用工具和最近草稿。搜索与“全部工具”进入独立目录。
2. 全部工具页支持用途关键词、多词搜索、类别筛选、清空输入与无结果恢复；类别只在有可用工具时出现。当前真实功能为制作证件照、更换底色、图片压缩、裁剪旋转。
3. 编辑页规格仅显示一次；背景底色／裁剪构图分成两个页签，原图对比独立在顶部。换色失败回退、草稿恢复、处理取消继续沿用已有保护。
4. 保存格式改为两行完整可点选项。保存成功后主按钮变为“完成，返回首页”，重复下载为次要按钮，并复用同账号、同格式已成功的结果。
5. “我的”改为紧凑身份区和中性额度区。额度明确写为“证件照保存机会”，避免未来文档工具误用这项说明。草稿清理统一放在作品的本地草稿页，并保留确认框。
6. 作品显示工具名称和真实更新时间。首页／我的进入草稿列表通过一次性导航意图选择本地页签，不覆盖用户之后手动选择的云端页签。

## 新功能怎样接入

展示配置集中在 [tool-catalog.js](../mini-program/utils/tool-catalog.js)，入口逻辑集中在 [tool-launcher.js](../mini-program/utils/tool-launcher.js)。首页和目录读取同一份数据，避免改一处漏一处。

以将来的文档工具为例，先实现真实 Skyline 页面并加入 `app.json`，再增加 `document` 类别和工具条目：

```js
// 示例只说明注册方式，当前产品中没有该占位入口。
{ id: 'document', name: '文档工具' }
{
  id: 'actual-document-tool',
  name: '实际功能名称',
  description: '用用户能理解的话说明用途',
  category: 'document',
  keywords: ['实际用途关键词'],
  icon: 'file',
  entry: { type: 'page', url: '/pages/actual-tool/actual-tool' }
}
```

- `entry.type: 'page'` 直接进入独立页面，不经过证件照选规格和选照片流程；`portrait` 专用于现有证件照链路。
- 类别与工具数组顺序决定目录顺序；`enabled: false` 隐藏未开放项；`quick: true` 进入最多三个常用入口。主推荐标题、说明、按钮和素材来自 `featured` 配置。
- 独立页面负责实际文件选择、大小／格式校验、处理、失败恢复和输出。只有确定在本机完成才能标记 `local: true`。登录、计次和广告按工具的实际服务规则接入，不能默认套用证件照配额。
- 需要草稿的工具可注册 `resumePage` 和 `draftName`，保存 `toolId`，由目录恢复路由。但当前持久层与作品缩略图仍面向图片；PDF、Word 等文件需另外实现文件类型、预览、清理与持久化契约，不能只加一条配置就宣称支持。
- 现有 `pages/document/` 是隐私与协议页，不作为后续文件处理入口。新功能不默认增加底部导航；只有形成独立、常用的用户任务后再评估导航变更。

## 自定义尺寸按钮与静默保存（2026-10-23追加）

按用户反馈，对现有控件做小幅调整，沿用当前视觉系统：自定义宽高同行输入，原右侧“使用”改为下方通栏“使用此尺寸”，高度48px，输入框不再被按钮挤窄。100—3000像素校验、行内错误、键盘避让与规格选择事件保持原逻辑。[原生按钮截图](design/expansion-v2/native-custom-size-button.png)；[300px键盘占位检查](design/expansion-v2/native-custom-size-keyboard-inset.png)。后者是模拟输入区占位，没有实际弹出手机键盘。

保存时缺少身份会直接走现有 `wx.login → /api/user/login`，完成后继续本次保存，移除额外登录确认框和页尾首次登录提示。已登录复用身份；多个调用复用同一登录请求。微信登录设置10秒超时，服务端请求保留15秒超时。仅在用户主动保存或登录时建立身份，退出后不在启动时自动重新登录；头像昵称依然单独主动填写。本地工具保存维持不依赖登录。

该调用方式对应 [微信官方 wx.login 文档](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/login/wx.login.html) 的登录凭证换取身份流程，前端不包含 AppSecret，照片后端接口及计次规则不变。隐私说明同步描述建立身份的时机。

新增4项回归，全量74项通过：覆盖静默登录与并发复用、失败重试、保存动作衔接、重复下载缓存，以及页面退出后阻止迟到保存。14份WXML编译通过。

官方模拟器375×812实际检查按钮宽335px、高48px；模拟键盘占位后按钮仍在输入区内。以演示图片、模拟登录／请求／相册回调运行未登录保存，最终 `saved=true`、`busy=false`，见 [保存前](design/expansion-v2/native-export-before-silent-save.png) 和 [保存成功](design/expansion-v2/native-silent-save-success.png)。测试后还原原账号、登录缓存、导出会话与所有替身。没有登录真实用户、消耗云端额度或写入真实相册；这些仍待手机验证。

## 尺寸弹窗与微信昵称引导（2026-10-23追加）

用户本轮要求：保留微信昵称快捷填写和审核、去掉自行填写引导；尺寸弹窗完整展示内容、无需滚动找确认，并改善 Skyline 动画。这是现有组件内的交互修正，沿用既有配色、字体和圆角，不重新生成概念图。

### 已实现

- 四个常用规格改为两列展示，去掉搜索与滚动容器；下方直接显示带“宽／高／px”标签的自定义输入区和独立确认操作。
- 点击规格先更新选中态、宽高和按钮文案（例如“使用二寸规格”），确认后才触发原 `select` 事件；取消不应用，重新打开恢复已应用的规格。宽高编辑切换为自定义，继续校验100—3000整数范围。
- 开启项目 `compileWorklet`，使用 `wx.worklet.shared`、`timing` 和 `applyAnimatedStyle` 让面板位移、遮罩透明度在 Skyline 原生动画链路中运行；进入260ms、退出180ms，不使用逐帧 `setData`。接口依据见 [微信官方 Worklet 文档](https://developers.weixin.qq.com/miniprogram/dev/framework/runtime/skyline/worklet.html)。
- 关闭动画结束后才移除节点并继续选图，期间防重复确认；父页面隐藏会撤销尚未送出的选择，卸载清理计时器与样式绑定。兼容当前基础库返回数字绑定ID（包括0）以及对象形式的回调，避免反复打开积累绑定。
- 键盘出现时收起常用规格区，保留自定义输入和确认；切换宽、高输入框的 blur 不再触发弹窗反复展开，实际高度由键盘事件控制。
- 资料页改为“微信昵称”“点击使用微信昵称”和键盘上方快捷选择的说明，保留官方昵称输入组件、表单收集及现有审核逻辑。平台能力只提供快捷填写，不提供限制输入来源的开关；因此没有宣称能强制只取真实微信昵称。此方案已获用户选择确认，依据见 [微信官方头像昵称填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/userProfile.html)。隐私说明同步调整。
