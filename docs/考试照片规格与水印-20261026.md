# 考试照片规格、品牌预览与水印工具

日期：2026-10-26。当前为本地开发及微信预览版本；按用户要求未部署线上后端，也未启动本地后端。小程序继续调用现有线上Java地址。

## 本轮交互

- 首页主制作和更换底色保留原有智能抠图、红蓝白与自定义背景、裁剪和六寸排版。常用尺寸弹层增加全部考试规格入口。
- 36项规格，其中32项考试/用途、4项常用尺寸；按公务招录、学历语言、资格职称、常用尺寸分组，支持考试简称和英文搜索。
- 规格详情区分固定像素、像素下限、比例要求和建议输出，给出年份、学校/地区适用范围、来源链接及核对日期。采用人事报名平台模板的职业资格明确标作平台参考，不声称单独核验了每项考试当年的全部细则。
- 详情提供智能制作/换底色与原图尺寸适配。原图适配不改人像背景；智能制作可换底，并在最终成品阶段适配所选考试尺寸和体积。考试禁止修图或要求专用采集时，应使用符合要求的原照和官方渠道。

## 保存及品牌水印

- 所有证件照/考试照片预览实际合成“拾光小相”品牌水印，不使用只覆盖在界面上的文字。长按和大图查看仅引用预览位图。
- 无水印原片与品牌预览路径分开；编辑页、导出页和草稿缩略图均不直接绑定无水印成品。旧草稿在打开时补生成品牌预览。
- 每天5次免费无水印保存，超限后仍走既有完整观看激励视频与服务端额度校验；考试照片亦纳入额度。未通过校验不写入相册，同张图重复下载复用已完成结果，不重复扣次数。维持原有每日完整观看5次后不限次数规则。
- 本地压缩/普通裁剪和独立自定义水印工具维持各自用途，不用本地工具绕开证件照导出流程。

## 清晰度修正

- 原图适配的品牌预览从原照按同一裁剪框生成，最长边保留至1600像素，不再用144×192或178×220的小成品放大预览。
- 智能制作的品牌预览从高清换底结果生成，标准尺寸/KB处理仅作用于实际导出文件。
- 普通裁剪改为无损PNG，最长边上限从2560提升至4096，避免每次裁剪额外JPEG压缩。
- 文件规范严格限制的小像素成品仍会在大图查看时显糊，界面解释高清预览与标准成品的区别，不用DPI或字节填充宣称提高图像细节。

## 自定义水印

新增POST /api/photo/watermark：multipart file/text/dpi，样式size/opacity/angle/color/space由Java按Python要求放入query。文件限制10MB/1600万像素/单边6000，文字1–60字，样式作范围校验。没有添加昵称或水印文字的内容审核。水印图片响应不写入请求日志。

独立文字水印工具的真实生成功能需部署本次新增Java接口；当前线上未更新。此限制不影响本地品牌预览水印及既有换底色功能。

## 已验证与边界

- 101项Node回归通过，涵盖核心入口、考试检索、JPEG元数据、取消/失败/重试、防止旧图导出、品牌位图绘制、配额拒绝不写相册、重复下载缓存。
- 4项Java测试通过：输入校验、默认样式、失败处理及真实HTTP参数契约；Python为本机契约替身，不冒充线上生成成功。
- Java8编译打包通过。
- 官方微信模拟器实际调用现有线上证件照/换底接口，演示照片生成白底和蓝底结果成功；品牌预览位图与干净成品分别输出。未登录真实账号、未播放实际广告、未写入真实相册或云端作品。
- 本机实际导出国考295×413、CPA178×220且低于20KB、NCRE144×192满足20–200KB、考研保持3:4的JPEG，Pillow复核格式和300DPI。
- 375×812原生页面及320×568窄容器压力检查；窄容器不是小屏真机。后续用户要求的品牌说明和双制作模式仍以本次最终预览真机验收为准。
- 自动化多页截图曾复用原生旧帧，重复截图不作为多页面视觉成功的依据；保留状态/位图验证，最终截图经前台窗口复核。
- 用户取消本地后端联调后未更改服务器或API基础地址。独立Python未对公网映射，未继续猜测端口。
